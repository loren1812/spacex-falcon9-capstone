# SpaceX Falcon 9 First-Stage Landing Prediction

IBM Data Science Professional Certificate – Applied Data Science Capstone.

| # | File | Content |
|---|------|---------|
| 1 | `01_data_collection_api.ipynb` | Data collection with the SpaceX REST API (saved copy) |
| 2 | `02_data_collection_webscraping.ipynb` | Web scraping of Falcon 9 launch records from Wikipedia |
| 3 | `03_data_wrangling.ipynb` | Data wrangling and landing-outcome label (Class) |
| 4 | `04_eda_sql.ipynb` | Exploratory data analysis with SQL (SQLite) |
| 5 | `05_eda_visualization.ipynb` | EDA with Matplotlib/Seaborn and feature engineering |
| 6 | `06_interactive_map_folium.ipynb` | Launch-site proximity analysis with Folium |
| 7 | `07_spacex_dash_app.py` | Interactive Plotly Dash dashboard |
| 8 | `08_machine_learning_prediction.ipynb` | Classification models (LogReg, SVM, Decision Tree, KNN) |

Final report: `Data Science Capstone Project Report.pdf`
